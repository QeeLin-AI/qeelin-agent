仓位设置

        

          
          
          
          
        

        

          杠杆只决定占用多少保证金、不放大风险。

          仓位大小：听交易员＝模型给多少用多少；按风险上限反推＝用 单笔风险上限 ÷ 止损幅度 反推名义敞口。

          注意：选「按风险上限反推」时以反推值为准，交易员 / 因子信号 / 风控官给出的仓位建议不参与最终仓位（方向与拒绝仍有效），决策页「仓位归因」可看到每一步的变化。
        

      


      

        
风险控制

        

          
          
          
          
          
          
          
          
        

        
·--

        

          前 4 项是互相联动的一组：单笔仓位上限 × 同时持仓品种数 就是「全部仓位打满要占多少保证金」，
          它必须 ≤ 保证金占用上限，否则按仓位上限开满后必然有仓被拒。不满足时保存会被拒绝，
          提示你先把保证金占用上限提上去。

          前 6 项都是硬顶（允许的上限），不代表实际会用满：设大只是放宽允许范围。
          实际仓位由上方「仓位大小」决定：听交易员时用模型给的 size，按风险上限反推时用 单笔风险上限 ÷ 止损 ÷ 杠杆。

          后 2 项是组合层敞口（单位：倍权益），约束多笔/多品种同向叠加的名义敞口，与保证金是两套算法：
          名义看「开了多大的仓」，保证金看「押了多少本金」。拦截告警会带上当前上限值。

LLM 自主调参
--

        
模型读取近期平仓表现与决策漏斗，提出小幅参数调整；能不能落地由代码裁决：
          只认白名单里的数值项、单项变化 ≤ 25%、一轮最多 3 项，越界即整份作废。
          只动风控与持仓参数，不涉及 API Key 与模型配置。
